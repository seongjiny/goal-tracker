# Goal Tracker 제품 계획

## 제품 정의

개인 또는 부부가 목표, 습관, 억제 행동, 측정값을 날짜와 반복 일정에 따라 기록하는 모바일 중심 웹 앱이다. 날짜 기준은 `Asia/Seoul`이다.

## 구현 범위

- 카카오 로그인, Supabase DB, 세션 복원
- 삭제되지 않는 개인 공간과 별도 우리 공간
- 초대 코드 참여, 나가기, 방장 이전, 개인 데이터 보존
- 공간별 목표 생성·수정·정렬·보관·복원
- 체크, 하루 N회, 억제 성공/실패, 수치 최소·최대·범위 목표
- 매일, 특정 요일, 주 N회, 격주, 매월, 격월 일정
- 날짜별 기록, 진행률, 연속 기록, 최근 7일
- 스와이프 편집, 고정 하단 탭, 브라우저 뒤로 가기
- Vitest 도메인 테스트와 Playwright 핵심 회귀 테스트

## 확정 정책

- 우리 공간 기록은 사용자별로 독립한다.
- 공동 목표는 두 구성원 모두 관리할 수 있다.
- 공유 탈퇴 시 공동 데이터는 공간에 유지한다.
- 기존 항목은 생성자의 개인 공간으로 이전한다.
- 목표 횟수 초과는 허용하지 않는다.
- 주 시작은 월요일이다.
- 없는 월말 지정일은 해당 월 마지막 날로 보정한다.
- 억제 목표 미입력은 성공으로 처리하지 않는다.
- 수치는 하루 한 값이며 단위를 자동 환산하지 않는다.

## 완료 검수

모든 변경은 기존 로그인, 공간 분리, CRUD, 기록, 날짜, 정렬, 보관, 모바일 UI의 회귀 검수를 포함한다. `lint`, `typecheck`, `test`, `test:e2e`, `build`가 모두 통과해야 완료다.

## 후속 후보

- 오늘 화면에서 목표 즉시 추가 UX
- 여러 공동 공간 UI
- 알림, 상세 통계, 데이터 내보내기
- 휴대폰 사용 시간 등 외부 데이터 자동 연동
- 공간 삭제 및 공동 데이터 내보내기
