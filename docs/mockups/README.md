# 1차 MVP 화면 시안

각 화면은 독립적으로 열 수 있는 정적 HTML 시안이다.

- [전체 화면 목록](index.html)
- [오늘](today.html)
- [기록](history.html)
- [항목 관리](items.html)
- [항목 추가 및 수정](item-form.html)
- [보관함](archive.html)

브라우저에서 `index.html`을 열거나 프로젝트 루트에서 아래 명령으로 확인한다.

```powershell
pnpm dev
```

시안은 UX와 정보 구조 검토용이며 실제 앱 컴포넌트는 아니다.
