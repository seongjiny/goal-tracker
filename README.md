# Goal Tracker

부부가 여러 목표, 습관, 일상 항목을 함께 관리하는 모바일 중심 기록 앱이다.

현재는 여러 Daily Item을 날짜별로 한 번씩 기록하는 1차 MVP를 개발한다.

## 시작

```powershell
pnpm install
pnpm dev
```

개발 서버는 기본적으로 `http://localhost:3000`에서 실행된다.

## 검증

```powershell
pnpm lint
pnpm typecheck
pnpm build
```
